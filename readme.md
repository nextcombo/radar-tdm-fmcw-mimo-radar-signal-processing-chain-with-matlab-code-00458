# Radar: TDM-FMCW-MIMO Radar Signal Processing Chain [with MATLAB Code]

The project is the implementation of a basic signal processing chain for ADAS vehicle TDM FMCW MIMO radar systems. There is increasing interest in the concept of virtual arrays and their role in improving angle resolution.
The radar system modeled for this system is an Uniform Linear Array (ULA), characterized by the following:
- Transmitter:
  - Peak power: 0.001 W
  - Gain: 36 dB
- Receiver preamplifier:
  - Gain: 40 dB
  - Noise figure: 4.5 dB
The radar system configuration is as follows:
- Working frequency (GHz): 77
- Maximum target range (m): 200
- Range resolution (m): 1
- Maximum target velocity (km/h): 230
- Scan time (microseconds): 7.33
- Scan bandwidth (MHz): 150
- Maximum beat frequency (MHz): 27.30
Note: Only the main components are modeled, with other components such as couplers and mixers omitted. Additionally, it is assumed that the antenna is isotropic.
Up-scan linear FMCW signal
In coherent MIMO radar systems, each antenna in the transmit array emits a orthogonal waveform. Due to this orthogonality, the transmitted signal can be recovered at the receiver array. Then, the physical measurements on the corresponding physical receive array can be stacked up to form the measurement values of the virtual array.
The diagram below shows the equivalent of the physical array and the virtual array in a bidirectional mode:
Please note that since each element in the transmit array is radiating independently, there is no beam forming in the transmit mode, which results in a wide beam pattern covering a larger field of view (FOV). This allows all targets in the FOV to be illuminated simultaneously. The receiver array then generates multiple beams to process all target echoes. Compared to traditional phased array radars that require continuous scanning to cover the entire FOV, this is another advantage of MIMO radar in applications requiring fast reaction times.
Time Division Multiplexing (TDM) is a method of achieving orthogonality between transmit channels.
